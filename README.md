# 円相（Ensō）

「ためない、整理しない、忘れるための裏紙」— 円形キャンバスに書いたメモが、時間の経過とともに自然に消えていくメモアプリ。

Notionのような体系化されたドキュメント置き場でも、ToDoアプリのような確定タスクの管理でも、Claude/ChatGPTのような具体的な壁打ち相手でもない。「この仕様なんか引っかかる」「AとBを組み合わせたら筋がいいかも」といった、まだ仕様にもタスクにもプロンプトにもなっていない思考の種を、他のツールに渡す前にいったん受け止める場所として作られている。個人用の円形メモとして始まり、アカウント連携・複数人でリアルタイムに編集できる共有キャンバスへと発展した。アプリ内の表記・ページタイトルは「円相（えんそう）」。

## 何もしなくていい、という設計

フォルダ分け・タグ付け・保存ボタンは無い。書いたメモは自動的に保存され（`localStorage`、ログイン時はサーバーとも同期）、指でなぞって手をかけたものだけが画面に残り、それ以外は放っておくだけで自然に消えていく。手動で消したい場合の消しゴムは用意されているが、基本設計上は「何もしない」ことが前提の挙動になっている。

- **経時フェード**：書いてから約3〜4時間で薄くなり始め、約10時間で大きく薄くなり、24時間で消える（物理削除はしない。`src/fade.ts`）
- **なぞって復活**：気になるメモに指で触れると、そのとき経過していた時間の一部（最大で寿命の15%ぶん）が巻き戻る（`src/memoStore.ts`の`reviveMemo`）。1回で満額回復するわけではなく、何度も繰り返しなぞり続けたメモだけが生き延びる——「まだ気にしている」という事実を、行為の積み重ねとして表現する設計
- **振り返りシークバー**：最大3日前まで遡って、その時点のキャンバスの状態を再現できる（`src/rewindSelector.ts`）。ただし過去のメモを一覧・検索する機能はあえて用意していない。検索性を上げてしまうと「なぞらなければ消えていく」という前提そのものが崩れるため

## なぜ「円」なのか

円は見た目のモチーフではなく、書ける領域そのものに物理的な上限を設けるための制約。パン・スクロールができず、円の外にはみ出して書くこともできない（座標はすべて円内にクランプされる）。

**時間による歯止め（消える）と、面積による歯止め（有限の円）**の二重構造により、新しく書き足すよりも、すでにあるメモをなぞって手入れするほうが自然に促される。

## 書く → 待つ → 手放す

1. **書く**：道具バー（ペン・マーカー・テキスト）で円の余白に思いつきをそのまま書きなぐる。持ち物チェックや買い物リストなど、あらかじめ用意されたテンプレートから始めることもできる
2. **待つ**：数時間〜1日で自然に消えていく。何度もなぞり続けて生き残ったものだけが、目に入るたびに存在感を保つ。メモをつまんで円を描くように振り回すと、この時間の流れ自体を早めたり戻したりもできる
3. **手放す**：本当に大事な内容を、PNG/TXTとして書き出し、Notionなど「育てる場所」へ渡す（`src/exportControl.ts`）

## SMUI（鯖江メガネUI）

このアプリのキャンバスは、個人・共有を問わずすべて「メガネのレンズ」というビジュアルモチーフの上に描かれている。これがSMUI（鯖江メガネUI）で、共有キャンバス固有の機能ではなく、個人キャンバスを含むアプリ全体の見た目のデザイン言語。

- **個人キャンバス＝単眼鏡（monocle）**：レンズ1枚＋片側のツル（チェーン付き）で構成される（`frameKind: "monocle"`、`src/main.ts`）。現時点では実験的な位置づけの見た目
- **共有キャンバス＝眼鏡（glasses）**：左右レンズ＋ブリッジが1本につながった連続領域として描かれる（`frameKind: "glasses"`、`src/frameShape.ts`・`src/frameGeometry.ts`）。選んだ形状の輪郭がそのまま描画・なぞり・移動のクランプ境界になる
- **フレームの柄**（`src/framePattern.ts`）：マット／べっ甲／クリア／木目の4種類。個人（単眼鏡）・共有（眼鏡）どちらのレンズにも、設定メニューの「見た目の設定」から同じ4柄を適用できる共通の仕組み
- レンズの形状自体（丸／楕円／長方形）は、個人・共有どちらも同じ3種類の幾何ロジックを再利用している（`getFrameShape`／`getGlassesFrameShape`）。ただし個人キャンバスでは形状の選択肢はUI上まだ公開しておらず、常に丸レンズ

## 画面構成

ヘッダー右側の2タブ（`src/main.ts`）で切り替える。URLの `?view=shared` に現在のタブが反映され、リロードや共有リンクでも維持される。

| タブ | 内容 |
|---|---|
| **キャンバス** | 個人用の円形メモ（単眼鏡）。手描き・テキスト入力・道具バー・振り返りシークバーがまとまっている |
| **共有** | 複数人で同時編集できる共有ボード（眼鏡）。ログインが必要 |

旧仕様にあった「振り返り」専用タブは廃止され、過去の状態を辿るシークバーはキャンバスタブ下部の操作パネルに統合されている。

画面左上の三本線メニュー（`src/settingsMenu.ts`）が、テーマ・見た目の設定（フレーム柄）・テンプレート・使い方ガイド・エクスポート・アカウント（ログイン/ログアウトはClerkウィジェット）をまとめたアプリ全体のメニューになっている。ログインするとクラウド同期・「共有」タブが有効になる。

## 技術スタック

- **フロントエンド**：TypeScript + Vite + Canvas API（UIフレームワークは使用していない）
- **アイコン**：Phosphor Icons（Bold weight）のSVGパスを`src/icons.ts`に直接埋め込み。npm依存としては追加していない
- **認証**：Clerk（`@clerk/clerk-js`）— 任意。未ログインでも個人キャンバスはローカルのみで利用できる
- **バックエンド連携**：`https://api.onunu.me`（REST + WebSocket、`src/apiClient.ts`・`src/realtimeSync.ts`）。クラウド同期と共有キャンバスに使用し、ログイン時のみ通信する
- **永続化**：個人メモ・カスタムテンプレートは常に`localStorage`。ログイン時はサーバー側にも保存され、他端末とWebSocket通知で同期される。共有キャンバスは`localStorage`を使わずサーバーが唯一の保存先

未ログインで個人キャンバスのみを使う場合、外部通信は一切発生しない。

## 個人キャンバスの機能

1. **円形キャンバス表示**（パン・スクロールなし。円全体を常に表示）。2本指ピンチで1〜3倍までズームでき、iOS純正ピンチズームは`preventDefault`で抑止している
2. **ドラッグでの手描き入力**（円の外にはみ出さないようクランプ、正規化座標(-1〜1)で保存するためウィンドウサイズが変わっても位置がずれない）
3. **経時フェード**：寿命に対する経過時間の比率で100%→60%→20%→消滅の4段階になる。「消えるまでの期間」は選択式をやめ、常に**1日固定**（`FIXED_LIFESPAN_DAYS`）にしたため、実際には書いてから約3.4時間で60%・約10.3時間で20%・24時間で消滅する。メモにホバーすると出る案内ピル（`src/reviveInfoPill.ts`）に、消えるまでの残り時間が`残り 1:50`のような時計表示（H:MM）で出る
4. **なぞって復活**：ストロークが触れると`reviveMemo`が呼ばれ、寿命の15%ぶんか経過時間のうち小さい方だけ巻き戻る。1ジェスチャー（pointerdown〜pointerup）につき1メモ1回のみ呼ばれるため、繰り返しなぞり続けたメモだけが生き延びる
5. **道具バー**：鉛筆・ペンは統合済み（`pen`）／マーカー／テキスト／選択／消しゴムの5種
   - 色：ペン・テキストは黒/赤/青の固定3プリセット＋ネイティブカラーピッカーによるカスタム色。マーカーはシアン/マゼンタ/イエロー（パステル寄りに調整済み）＋カスタム色。ツールバーのペン・マーカーボタン自体にも選択中の色がプレビューされる（GoodNotes風、`toolbar.ts`の`syncToolIcons()`）
   - 太さ：ペンは1〜10pxの連続スライダー、マーカーは11px固定。消しゴムは小/中/大の3段階
   - 選択・消しゴムのツール選択中はカラーパレットを無効化する
6. **「選択」道具（旧・移動道具）**：メモを掴んでドラッグすると位置だけ移動できる（内容・見た目は変えない、円の外にはみ出さないようクランプ）。加えて、メモを掴んだまま円を描くように振り回すと時計を進める/戻す操作になり、時計回りでフェードを促進、反時計回りでなぞり復活と同じ効果が得られる（連続回転で加速。判定は1回転→270度・半径24px→16pxまで緩和済み、`src/canvasView.ts`の`ROTATE_STEP_RAD`/`ROTATE_MIN_RADIUS_PX`）
7. **テキスト入力**：道具バーで「テキスト」を選び円内をタップすると`<textarea>`が現れる。IME変換中のEnter/Escapeでは確定・取消せず、blurで確定、Escapeで取消。既存テキストメモをテキスト道具でタップすると編集モードで開き、全文削除して確定するとメモごと削除される
8. **テンプレート**：空のキャンバス中央の「＋テンプレートを使用」から、あらかじめ用意した定型文をそのまま配置できる（持ち物チェック／買い物リスト／今日の予定／打ち合わせメモ／考えをまとめる）。ユーザーが見出しと項目を自分で入力してカスタムテンプレートを作成・保存・削除でき（`localStorage`の`customTemplates`）、以降は組み込みテンプレートと同じ一覧に並ぶ
9. **使い方ガイド**（`src/usageGuide.ts`）：初回はテンプレート選択前に自動表示、以降は左上の設定メニュー内の「使い方」からいつでも開ける。「序（円相の由来）→練（サンドボックス体験）→結」の3ページ構成。「練」では本物とは別の使い捨てインスタンス・60倍速の仮想時計を使い、「掴んで回す」「振り返りシークバー」を実際に操作して体験できる

## 共有キャンバス：チームでの一次受け

個人の「一枚円」の考え方をチームに拡張したのが「共有」タブ。招待リンクで複数人が同じキャンバス（SMUIの眼鏡バリエーション）に書き込める。ログイン必須（未ログインだとログイン誘導だけが表示される、`src/sharedRoomMenu.ts`）。

- **ルームの作成・参加・退出**（`src/sharedRoomMenu.ts`・`src/sharedCanvas.ts`）：「＋新しい共有キャンバスを作る」でルームを作成し、招待リンク（URLの`?join=`パラメータ）を発行・コピーできる。ルーム名の変更・退出・削除はバックエンドAPIに接続済み（退出して残りメンバーが0人になるとルーム自体もサーバー側で自動削除）
- **見た目の設定**（`src/appearanceSelector.ts`）：レンズ形状と柄をまとめて選ぶ設定メニュー内の区画。**ルームマスターのみ変更可能**で、変更内容はサーバーに保存され全メンバーに同期される
- **同期方式**（`src/sharedCanvasSync.ts`・`src/realtimeSync.ts`）：変更は2秒デバウンスしてサーバーへPUT。他メンバーの変更は個人キャンバスと共用の1本のWebSocket接続でルーム単位に購読し、通知を受けたらすぐ取得し直すことでほぼ即時に反映する。通知の取りこぼしに備え、15秒間隔のポーリングGETも保険として並行して動く。WebSocket接続には30秒以内に5回以上切断するフラッピングを検知すると3分間再接続を止める「サーキットブレーカー」があり、接続不安定時のタブフリーズを防ぐ
- **共同アイデア出しセッション**（`src/sessionPanel.ts`）：ルームマスターが各フェーズの時間・参加人数上限（最大4人）をスライダーで設定して開始する4フェーズ制の機能
  1. **アイデア出し**：参加者ごとに固定パレットから1色が割り当てられ、色がロックされる。最大2組（4レンズ）に見た目上分割し、レンズごとに並行して書き込める（`src/lensSplit.ts`）。参加者のいない空きレンズは半透明のグレーアウト表示になる
  2. **議論**：ルームマスター以外は書き込み禁止（読み取り専用）。アイデア出しと同じレンズ分割表示を維持したまま進行する
  3. **採択・絞り込み**：メモを「選択」道具で振り回すと時間操作の代わりに熱量（heat）投票としてカウントされ、投票確定後のメモは`fadeExempt`でフェード対象から恒久的に除外される
  4. **結果**：投票確定後は全員が読み取り専用になり、確定から24時間で対象メモが自動削除される（エクスポートでの保存を案内）。ルームマスターが「編集を再開」を押すまでこの状態が続く
  - 開始・進行・延長・終了・編集再開はルームマスターのみ操作できる
- 道具バー・色・テンプレート配置・なぞり復活・消しゴム・位置移動など、描画に関する操作自体は個人キャンバスと同じ実装（`src/canvasView.ts`）を共有している

## アカウント・クラウド同期

ログイン（Clerk）は必須ではないが、ログインすると以下が有効になる。

- **個人キャンバスのクラウド同期**（`src/cloudSync.ts`）：ログイン時に一度サーバーとローカルを同期し、以降はローカルの変更をデバウンスしてサーバーへ保存する
- **他端末とのリアルタイム反映**（`src/realtimeSync.ts`）：WebSocket（`wss://api.onunu.me/ws`）で「変更があった」という通知だけを受け取り、受け取るたびにサーバーから取得し直してローカルへ反映する。切断時は指数バックオフで再接続する（上記のサーキットブレーカーも適用）
- **「共有」タブの利用**：前述のとおりログイン必須

いずれも認証にはClerkのセッショントークンを使い（`src/apiClient.ts`）、未ログイン時はこれらの通信は一切発生しない。

## 実装メモ・意思決定

- メモは「道具」「色」「消えるまでの期間」をメモ単位で1つずつ持つ（ストローク単位ではない）。1つの連続したドラッグ操作、または短い間隔（1.4秒以内）で続けて書いたストロークは同じメモとして扱う
- 「なぞる」判定は、ドラッグ経路上の各点と既存メモのストローク（線分群）との距離がしきい値（12px）以内かどうかで行う。消しゴムが選ばれている間は、なぞり復活ではなく常に消去として扱う
- 消しゴムは本当の手動削除（ドラッグで触れた部分だけをその場で消す）。「円相」は元々『手動削除できず、時間経過かなぞり復活でしか消えない』という設計思想だったが、ユーザーの明示的な指示によりこの原則を上書きしている
- 円のサイズはウィンドウ幅・高さに応じて動的に決まる（`ResizeObserver`でコンテナサイズを常時監視し、幅と高さのうち小さい方いっぱいまで正方形として広げる。下限200px・上限1100px、`src/canvasSizing.ts`）
- `Memo` は `kind: "stroke" | "text"` の判別可能な union 型で、描画は`src/memoRenderer.ts`の`renderMemoAt`に共通化されている。`heat`・`fadeExempt`はセッション投票機能用のフィールドで、個人キャンバスでは通常未使用

## 既知の制約

- Google Fonts（Klee One / Noto Sans JP）はオンライン環境でのみ読み込まれる。オフラインやフォント読み込み失敗時はシステムのsans-serifにフォールバックする（レイアウト・機能には影響しない）
- 「共有」タブの利用にはログインが必須。`.env.local`にClerkの鍵が未設定の環境では実質使えない
- クラウド同期・共有キャンバスは外部API（`api.onunu.me`）への通信が前提のため、オフラインではログイン中でも同期は行われない（未ログイン時の個人キャンバスはオフラインでも従来どおり動作する）
- 共有キャンバスの同期はWebSocket通知＋デバウンス送信によるほぼ即時反映だが、本格的な競合解決（同時編集時の差分マージ等）は行わず、最後に保存した内容が勝つ単純な方式。サーバー側に購読解除の仕組みが無いため、過去に見たルームの通知もソケット接続中は届き続ける（クライアント側で今表示中のルームかどうかを見て無視している）
