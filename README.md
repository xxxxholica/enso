# 円相（Ensō）

「積み上げるな、なぞれ」— 円形キャンバスに書いたメモが時間経過で自然に消えていくメモアプリ。
個人向けの円形メモとして始まり、その後アカウント連携・複数人でのリアルタイム共有キャンバス（通称SMUI／鯖江メガネUI）へと拡張された。
アプリ内の表記・ページタイトルは「円相（えんそう）」（旧名「一枚円」）。

## 画面構成

ヘッダーの2タブ（`src/main.ts`）で切り替える。URLの `?view=shared` に現在のタブが反映され、リロードや共有リンクでも維持される。

| タブ | 内容 |
|---|---|
| **キャンバス** | 個人用の円形メモ。手描き・テキスト入力・道具バー・振り返りシークバーはすべてこのタブ内 |
| **共有** | 眼鏡フレーム形の1枚のキャンバスを、招待リンクで複数人が同時に編集する共有ボード（SMUI）。ログイン必須 |

旧仕様にあった「振り返り」専用タブは廃止され、過去の状態を辿るシークバーはキャンバスタブ下部の操作パネルに統合されている（後述）。

ヘッダー右上のアカウントウィジェットはログイン状態を問わず常に表示され、ログインするとクラウド同期・「共有」タブが有効になる。ヘッダーの「使い方」ボタンから、いつでも由来と基本操作の案内（使い方ガイド）を開ける。

## 技術スタック

- TypeScript + Vite + Canvas API（UIフレームワークなし）
- 認証: Clerk（`@clerk/clerk-js`）— **任意**。未ログインでも「キャンバス」タブは従来どおりローカルのみで動作する
- クラウド同期・共有キャンバス用API: `https://api.onunu.me`（REST + WebSocket、`src/apiClient.ts`・`src/realtimeSync.ts`）— **ログイン時のみ**通信する
- 永続化: 個人メモ・カスタムテンプレートは常に `localStorage`。ログイン時はサーバー側にも保存され、他端末とWebSocket通知で同期される。共有キャンバスは `localStorage` を使わずサーバーが唯一の保存先

未ログインで「キャンバス」タブのみを使う場合は、外部通信なし・`localStorage`のみで完結する。

## 使い方

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 型チェック + 本番ビルド（dist/ に静的ファイル出力）
npm run preview   # dist/ をローカルで確認
npm run test      # vitest（フェード計算・当たり判定・同期ロジックのユニットテスト）
```

`dist/` の中身はそのまま Vercel / Netlify / GitHub Pages 等の静的ホスティングに配置できる。

認証を有効にするには `.env.local` に `VITE_CLERK_PUBLISHABLE_KEY` を設定する（`src/clerkAccount.ts`）。未設定でもアプリ自体は起動し、「アカウント機能: `.env.local` に `VITE_CLERK_PUBLISHABLE_KEY` が未設定です」という警告バッジが出るだけで個人キャンバスは通常どおり使える。ただし「共有」タブ（SMUI）はログイン必須のため、鍵が無い環境では実質使えない。

## 個人キャンバスの機能

1. **円形キャンバス表示**（パン・スクロールなし。円全体を常に表示）。2本指ピンチで1〜3倍までズームでき、iOS純正ピンチズームは`preventDefault`で抑止している
2. **ドラッグでの手描き入力**（円の外にはみ出さないようクランプ、正規化座標(-1〜1)で保存するためウィンドウサイズが変わっても位置がずれない）
3. **経時フェード**（0–24h相当:100% / 24h–3日相当:60% / 3日–7日相当:20% / 消滅・`status:"faded"`、物理削除はしない）。「消えるまでの期間」は選択式をやめ、常に**1日固定**（`src/fade.ts` の `FIXED_LIFESPAN_DAYS`。視認負荷低減のため「期間を選ぶ」操作自体を無くした判断）
4. **なぞって復活**：ストロークに触れると即座に100%へ（確認ダイアログなし）
5. **道具バー**：鉛筆・ペンは統合済み（`pen`）／マーカー／テキスト／選択／消しゴムの5種
   - 色：ペン・テキストは黒/赤/青の固定3プリセット＋ネイティブカラーピッカーによるカスタム色。マーカーはシアン/マゼンタ/イエロー（パステル寄りに調整済み）＋カスタム色
   - 太さ：ペンは1〜10pxの連続スライダー、マーカーは11px固定。消しゴムは小/中/大の3段階
   - 選択・消しゴムのツール選択中はカラーパレットを無効化する
6. **「選択」道具（旧・移動道具）**：メモを掴んでドラッグすると位置だけ移動できる（内容・見た目は変えない、円の外にはみ出さないようクランプ）。加えて、メモを掴んだまま円を描くように振り回すと時計を進める/戻す操作になり、時計回りでフェードを促進、反時計回りでなぞり復活と同じ効果が得られる（連続回転で加速）。位置移動・時間操作のいずれも `traceHistory` は移動そのものでは更新しない
7. **テキスト入力**：道具バーで「テキスト」を選び円内をタップすると`<textarea>`が現れる。IME変換中のEnter/Escapeでは確定・取消せず、blurで確定、Escapeで取消（`isComposing`判定あり）。既存テキストメモをテキスト道具でタップすると編集モードで開き、全文削除して確定するとメモごと削除される
8. **振り返りシークバー**：下部操作パネル右側のスライダーで、直近「たった今」から最大3日前までの好きな時点にスライドし、その瞬間のキャンバスの状態（なぞり直し履歴 `traceHistory` を含む）を再現できる。遡っている間は道具バー全体を無効化する。目盛りは相対時間表現のみ（絶対時刻は出さない）で、意図的に検索性を下げている——「なぞらなければ消えていく」というコンセプトに反しないよう、消えたメモを後から一覧・検索できないようにするための設計判断
9. **テンプレート**：空のキャンバス中央の「＋テンプレートを使用」から、あらかじめ用意した定型文をそのまま配置できる（持ち物チェック／買い物リスト／今日の予定／打ち合わせメモ／考えをまとめる）。加えて、ユーザーが見出しと項目を自分で入力してカスタムテンプレートを作成・保存・削除でき（`localStorage`の`customTemplates`）、以降は組み込みテンプレートと同じ一覧に並ぶ
10. **使い方ガイド**（`src/usageGuide.ts`）：初回はテンプレート選択前に自動表示、以降はヘッダーの「使い方」ボタンからいつでも開ける。「序（円相の由来）→練（サンドボックス体験）→結」の3ページ構成。「練」では本物とは別の使い捨てインスタンス・60倍速の仮想時計を使い、「掴んで回す」「振り返りシークバー」を実際に操作して体験できる

## 共有キャンバス（鯖江メガネUI／SMUI）

「共有」タブは個人キャンバスとは別物で、複数人が同じキャンバスをリアルタイムに近い形で編集できる機能。ログイン必須（未ログインだとログイン誘導だけが表示される、`src/sharedRoomMenu.ts`）。

- **フレーム形状**（`src/frameShape.ts`・`src/frameGeometry.ts`）：丸／楕円／長方形（角丸）に加え、共有キャンバス専用の眼鏡フレーム形状（左右レンズ＋ブリッジが1本につながった連続領域）。選んだ形状の輪郭がそのまま描画・なぞり・移動のクランプ境界になる。`frameShape.ts`が輪郭の幾何、`frameGeometry.ts`がサイズ確定・状態管理・縁取り描画を担当する役割分担
- **フレームの柄**（`src/framePattern.ts`）：マット／べっ甲／クリア／木目の4種類（共有キャンバス専用、個人キャンバスは単色のまま）
- **見た目の設定**（`src/appearanceSelector.ts`）：フレーム形状と柄をまとめて選ぶポップアップ。**ルームマスターのみ変更可能**で、変更内容はサーバーに保存され全メンバーに同期される
- **ルームの作成・参加・退出**（`src/sharedRoomMenu.ts`・`src/sharedCanvas.ts`）：「＋新しい共有キャンバスを作る」でルームを作成し、招待リンク（URLの`?join=`パラメータ）を発行・コピーできる。ルーム名の変更・退出・削除はバックエンドAPIに接続済み（退出して残りメンバーが0人になるとルーム自体もサーバー側で自動削除）。ルーム名の操作はホバー（PC）／長押し（タッチ）のメニューに統合されている
- **同期方式**（`src/sharedCanvasSync.ts`・`src/realtimeSync.ts`）：変更は2秒デバウンスしてサーバーへPUT。他メンバーの変更は個人キャンバスと共用の1本のWebSocket接続でルーム単位に購読し、通知を受けたらすぐ取得し直すことでほぼ即時に反映する。通知の取りこぼしに備え、15秒間隔のポーリングGETも保険として並行して動く。WebSocket接続には30秒以内に5回以上切断するフラッピングを検知すると3分間再接続を止める「サーキットブレーカー」があり、接続不安定時のタブフリーズを防ぐ
- **共同アイデア出しセッション**（`src/sessionPanel.ts`、issue #59）：ルームマスターが各フェーズの時間・参加人数上限をスライダーで設定して開始する3フェーズ制の機能
  1. **アイデア出し**：参加者ごとに固定パレットから1色が割り当てられ、色がロックされる
  2. **議論**：ルームマスター以外は書き込み禁止（読み取り専用）になる
  3. **採択・絞り込み**：メモを「選択」道具で振り回すと時間操作の代わりに熱量（heat）投票としてカウントされ、投票確定後のメモは`fadeExempt`でフェード対象から恒久的に除外される
  - 開始・進行・延長・終了はルームマスターのみ操作できる
- 道具バー・色・テンプレート配置・なぞり復活・消しゴム・位置移動など、描画に関する操作自体は個人キャンバスと同じ実装（`src/canvasView.ts`）を共有している

## アカウント・クラウド同期

ログイン（Clerk）は必須ではないが、ログインすると以下が有効になる。

- **個人キャンバスのクラウド同期**（`src/cloudSync.ts`）：ログイン時に一度サーバーとローカルを同期し、以降はローカルの変更をデバウンスしてサーバーへ保存する
- **他端末とのリアルタイム反映**（`src/realtimeSync.ts`）：WebSocket（`wss://api.onunu.me/ws`）で「変更があった」という通知だけを受け取り、受け取るたびにサーバーから取得し直してローカルへ反映する。切断時は指数バックオフで再接続する（上記のサーキットブレーカーも適用）
- **共有キャンバス（SMUI）タブの利用**：前述のとおりログイン必須

いずれも認証にはClerkのセッショントークンを使い（`src/apiClient.ts`）、未ログイン時はこれらの通信は一切発生しない。

## 実装メモ・意思決定

- メモは「道具」「色」「消えるまでの期間」をメモ単位で1つずつ持つ（ストローク単位ではない）。1つの連続したドラッグ操作、または短い間隔（1.4秒以内）で続けて書いたストロークは同じメモとして扱う。道具・色を切り替えると書きかけのセッションは自動的に閉じ、次のストロークは新しいメモとして始まる
- 「なぞる」判定は、ドラッグ経路上の各点と既存メモのストローク（線分群）との距離がしきい値（12px）以内かどうかで行う。消しゴムが選ばれている間は、なぞり復活ではなく常に消去として扱う
- 消しゴムは本当の手動削除（ドラッグで触れた部分だけをその場で消す）。「円相」は元々『手動削除できず、時間経過かなぞり復活でしか消えない』という設計思想だったが、ユーザーの明示的な指示によりこの原則を上書きしている
- 円のサイズはウィンドウ幅・高さに応じて動的に決まる（`ResizeObserver`でコンテナサイズを常時監視し、幅と高さのうち小さい方いっぱいまで正方形として広げる。下限200px・上限1100px、`src/canvasSizing.ts`）
- `Memo` は `kind: "stroke" | "text"` の判別可能な union 型で、描画は`src/memoRenderer.ts`の`renderMemoAt`に共通化されている。`heat`・`fadeExempt`はセッション投票機能用のフィールドで、個人キャンバスでは通常未使用

## 既知の制約

- Google Fonts（Klee One / Noto Sans JP）はオンライン環境でのみ読み込まれる。オフラインやフォント読み込み失敗時はシステムのsans-serifにフォールバックする（レイアウト・機能には影響しない）
- 「共有」タブ（SMUI）はログイン必須。`.env.local`にClerkの鍵が未設定の環境では実質使えない
- クラウド同期・共有キャンバスは外部API（`api.onunu.me`）への通信が前提のため、オフラインではログイン中でも同期は行われない（未ログイン時の個人キャンバスはオフラインでも従来どおり動作する）
- 共有キャンバスの同期はWebSocket通知＋デバウンス送信によるほぼ即時反映だが、本格的な競合解決（同時編集時の差分マージ等）は行わず、最後に保存した内容が勝つ単純な方式。サーバー側に購読解除の仕組みが無いため、過去に見たルームの通知もソケット接続中は届き続ける（クライアント側で今表示中のルームかどうかを見て無視している）
