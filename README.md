# 円相（Ensō）

「ためない、整理しない、忘れるための裏紙」— 正方形・角丸のキャンバスに書いたメモを、そのまま置いておける個人用メモアプリ。

Notionのような体系化されたドキュメント置き場でも、ToDoアプリのような確定タスクの管理でも、Claude/ChatGPTのような具体的な壁打ち相手でもない。「この仕様なんか引っかかる」「AとBを組み合わせたら筋がいいかも」といった、まだ仕様にもタスクにもプロンプトにもなっていない思考の種を、他のツールに渡す前にいったん受け止める場所として作られている。完全にローカルで動く個人用のキャンバス。アプリ内の表記・ページタイトルは「円相（えんそう）」——プロダクト名としては維持しているが、キャンバスの形状自体は下記の通り正方形・角丸（ネイティブ版の設計決定に合わせた変更）。

## 何もしなくていい、という設計

フォルダ分け・タグ付け・保存ボタンは無い。書いたメモは自動的に`localStorage`へ保存され、消しゴムで触れない限りそのまま残り続ける。整理する必要も、消えてしまう前に何かする必要も無い——汚くていい作業台として、書きたいときに書いて、要らなくなったら自分の手で消すだけの設計になっている。

## なぜキャンバスに枠があるのか

枠は見た目のモチーフではなく、書ける領域そのものに物理的な上限を設けるための制約。パン・スクロールができず、枠の外にはみ出して書くこともできない（座標はすべて枠内にクランプされる）。キャンバスは1枚・正方形（角丸）で、パン/スクロールは無い。

有限の面積という歯止めにより、際限なく書き足すのではなく、枠の中に収まる範囲でその都度書き直したり消したりすることが自然に促される。

## 書く → 手放す

1. **書く**：道具バー（ペン・マーカー・テキスト）でキャンバスの余白に思いつきをそのまま書きなぐる
2. **手放す**：本当に大事な内容を、PNG/TXTとして書き出し、Notionなど「育てる場所」へ渡す（`src/exportControl.ts`）。書きなぐったままのメモは、要らなくなれば消しゴムでその場で消す

## フレーム

キャンバスは正方形・角丸の枠（`src/frameShape.ts`の`CANVAS_FRAME_SHAPE`、`src/frameGeometry.ts`）で描かれている。角丸の半径は具体的な指定がまだ無いため、見た目として自然な値を仮置きしている。枠線は持たず、紙の輪郭に沿ったdrop-shadowで浮かせる見た目にしている（柄の選択肢は撤去済み）。

（旧版は「メガネのレンズ」という円形のビジュアルモチーフ上に個人キャンバスを描いていたが、ネイティブ版のキャンバス形状決定（正方形・角丸）に合わせてこのWeb版でも置き換えた。レンズの丸み・柄の質感表現・単眼鏡のツル（チェーン）飾りなど円形専用の描画ロジックは撤去し、正方形・角丸のシンプルな境界判定に一本化している。）

## 技術スタック

- **フロントエンド**：TypeScript + Vite + Canvas API（UIフレームワークは使用していない）
- **アイコン**：Phosphor Icons（Bold weight）のSVGパスを`src/icons.ts`に直接埋め込み。npm依存としては追加していない
- **永続化**：`localStorage`のみ。サーバーとの通信は一切行わない

外部通信は一切発生しない、完全にローカルで動くアプリ。

## セットアップ

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 型チェック + 本番ビルド（dist/ に静的ファイル出力）
npm run preview   # dist/ をローカルで確認
npm run test      # vitest（当たり判定・永続化ロジックのユニットテスト）
```

`dist/` の中身はそのまま Vercel / Netlify / GitHub Pages 等の静的ホスティングに配置できる。ビルド成果物はSPAではなく単一の静的`index.html`のため、追加のルーティング設定（rewrite等）は不要。

## デプロイ

本番は [enso.hinata.works](https://enso.hinata.works) で公開している。デプロイは`npm run build`で生成した`dist/`をそのままホスティング先に配置するだけで、サーバー側の状態は持たない（永続化はブラウザの`localStorage`のみ）。

## 機能

1. **正方形・角丸のキャンバス表示**（パン・スクロールなし。キャンバス全体を常に表示）。2本指ピンチで1〜3倍までズームでき、iOS純正ピンチズームは`preventDefault`で抑止している
2. **ドラッグでの手描き入力**（キャンバスの外にはみ出さないようクランプ、正規化座標で保存するためウィンドウサイズが変わっても位置がずれない）
3. **道具バー**：ペン（鉛筆とは統合済み）／マーカー／テキスト／選択／消しゴムの5種
   - 色：ペン・テキストは黒/赤/青の固定3プリセット＋色相スライダーによるカスタム色。マーカーはシアン/マゼンタ/イエロー（パステル寄りに調整済み）＋カスタム色。ツールバーのペン・マーカーボタン自体にも選択中の色がプレビューされる（GoodNotes風、`toolbar.ts`の`syncToolIcons()`）
   - 太さ：ペン・マーカーはそれぞれ固定太さ（PC操作でのペンは太さを都度選ぶ必要が薄いため）。消しゴムは小/中/大の3段階
   - 選択・消しゴムのツール選択中はカラーパレットを無効化する
4. **「選択」道具**：メモを掴んでドラッグすると位置だけ移動できる（内容・見た目は変えない、キャンバスの外にはみ出さないようクランプ）
5. **消しゴム**：ドラッグで触れた部分だけをその場で消す本当の手動削除。手描きメモはストロークが分断される場合は複数本に分け、全て消えたメモは配列から取り除く。テキストメモは当たり判定用のボックスに触れると丸ごと削除される
6. **テキスト入力**：道具バーで「テキスト」を選びキャンバス内をタップすると`<textarea>`が現れる。IME変換中のEnter/Escapeでは確定・取消せず、blurで確定、Escapeで取消。既存テキストメモをテキスト道具でタップすると編集モードで開き、全文削除して確定するとメモごと削除される
7. **元に戻す/やり直す**：ツールバーの「戻る」ボタン（道具を問わず使える）のほか、Ctrl+Z（Cmd+Z）でundo、Shift+Ctrl+Z（Shift+Cmd+Z）でredo。タッチでは「選択」道具を選んでいる間だけ、2本指タップでundo、3本指以上のタップでredoに割り当てている（`src/memoStore.ts`のundoStack/redoStack、直近50件）
8. **書き出し**：設定メニューの「エクスポート」からPNG/TXTでダウンロードできる（`src/exportControl.ts`）
9. **使い方ガイド**（`src/usageGuide.ts`）：初回は自動表示、以降は左上の設定メニュー内の「使い方」からいつでも開ける。「序（円相の由来）→練（サンドボックス体験）→結」の3ページ構成。「練」では本物とは別の使い捨てインスタンスを使い、「書く」「消しゴムで消す」を実際に操作して体験できる（`src/tutorialSandbox.ts`）
10. **朝リセットと過去めくり**（`src/dailyReset.ts`・`src/archiveCanvas.ts`・`src/recordGrid.ts`）：起動時・フォアグラウンド復帰時に、前回使用日（ローカル暦日）から日付が変わっていれば当日のキャンバスを`archive:<日付>`へ退避して白紙に戻す（自動削除は無く無期限保持。何も書かれていない日はアーカイブを作らない）。初回発生時だけ「指定しなかったメモはサイレント保存されています」という一言ヒントを出す。過去へ戻る入口はフッターの記録一覧トリガー1箇所に統合されている（`toolbar.ts`の`buildRecordGridTrigger`）：
    - トリガー自体が最新の記録のサムネイルを表示し、両脇の◀▶で1日ずつ過去めくり画面（読み取り専用、`#history-view`）を行き来できる。◀（1日戻る）は常に有効、▶（1日進む）は今日を見ている間だけ非活性
    - トリガーをタップすると、3×3固定グリッドの記録一覧画面（`#record-grid-view`）が開く。日〜土＋前週／次週の9マス構成で、書き込みのあった日だけタップ可能なセルになり、それ以外はダミーセル（曜日バッジ）。今日のマスは実データの有無に関わらず常にタップ可能で、どれだけ過去へ潜っても一発で今日へ戻れる
    - 本体キャンバス・過去めくり画面・記録一覧画面は`#canvas-panel`内でフェード切り替えする同一領域の3画面（一覧・独立モーダルではなくキャンバスの差し替え方式）。過去めくり画面を表示中は道具バーの道具選択を操作不可にする（読み取り専用のため）
    - 過去のメモをドラッグして画面右端のドロップ帯まで運ぶと、元のメモはそのままに、正規化座標で±0.03程度ランダムにずらした位置へ複製を持ち出せる（`MemoStore.insertCopy()`）
    - 閲覧中の日付は`?view=past&date=YYYY-MM-DD`としてURLに反映され（`history.replaceState`）、リロードしても状態が復元される。`date`が不正な形式・今日以降を指す場合はパラメータを無視し通常表示から始める

## 実装メモ・意思決定

- メモは「道具」「色」をメモ単位で1つずつ持つ（ストローク単位ではない）。1つの連続したドラッグ操作、または短い間隔（1.4秒以内）で続けて書いたストロークは同じメモとして扱う
- 消しゴムの当たり判定は、ドラッグ経路上の各点と既存メモのストローク（線分群）との距離がしきい値（12px）以内かどうかで行う
- キャンバスのサイズはウィンドウ幅・高さに応じて動的に決まる（`ResizeObserver`でコンテナサイズを常時監視し、幅と高さのうち小さい方いっぱいまで正方形として広げる。下限200px・上限1100px、`src/canvasSizing.ts`）
- `Memo` は `kind: "stroke" | "text"` の判別可能な union 型で、描画は`src/memoRenderer.ts`の`renderMemoAt`に共通化されている
- コアループの利用実態計測（E8-06）：エクスポート（PNG/TXT）操作のたびに`exportEvents`へ`{timestamp, kind}`を記録し、朝リセットでアーカイブする際にその日のうちにエクスポートが使われていたかを`archiveExportFlags`へ日付ごとに記録する（`src/storage.ts`）。集計用のダッシュボードやUI表示は持たず、後からlocalStorageの中身を直接見て集計する前提

## 既知の制約

- Google Fonts（Klee One / Noto Sans JP）はオンライン環境でのみ読み込まれる。オフラインやフォント読み込み失敗時はシステムのsans-serifにフォールバックする（レイアウト・機能には影響しない）
- メモは消しゴムで消さない限り自動では消えない。日付が変わると当日のキャンバスは朝リセットで`archive:<日付>`へ自動退避され無期限保持されるが（「朝リセットと過去めくり」参照）、フォルダ分け・タグ付け・検索の機能は無いため、退避済みの過去のメモを見返す手段は1日ずつめくって目視するか、書き出し（PNG/TXT）に限られる
- 消しゴムで手動削除する以外に、メモを一括で消す手段は無い
